# 🔧 Blacksmith v0.2.3 - Installation & Uninstall Improvements

This release improves the installation documentation and enhances the uninstall command with better virtual environment handling.

## ✨ Improvements

### Uninstall Command Enhancements

- **Virtual Environment Deletion Confirmation**: The `blacksmith uninstall` command now prompts users to confirm before deleting the virtual environment, giving them control over whether to keep or remove it.
- **Active Venv Handling**: When uninstalling from within an active virtual environment, the command now:
  - Detects that the venv is currently active
  - Creates a cleanup script that will automatically delete the venv after deactivation
  - Provides clear instructions for completing the removal process
- **Better User Experience**: Improved messaging and guidance throughout the uninstall process

### Documentation Updates

- **Simplified Installation**: Removed one-liner installation scripts in favor of manual virtual environment setup, which provides better control and avoids PATH issues
- **Clearer Instructions**: Updated README with step-by-step virtual environment creation and activation instructions for all platforms
- **Improved Troubleshooting**: Enhanced troubleshooting section with better guidance for virtual environment usage

## 📦 Installation

```bash
# Upgrade from previous version
pip install --upgrade jdi-blacksmith

# Or fresh install (recommended: use a virtual environment)
python3 -m venv ~/.blacksmith-venv
source ~/.blacksmith-venv/bin/activate  # Linux/macOS
# Windows: ~\.blacksmith-venv\Scripts\Activate.ps1
pip install jdi-blacksmith
```

## 🔄 Migration Notes

If you were using the one-liner installation scripts (`install.sh` or `install.ps1`), please follow the new manual installation instructions in the README. The scripts have been removed in favor of a more transparent installation process.

## 📝 Technical Details

- Uninstall command now checks if `sys.executable` is within the `.blacksmith-venv` directory to detect active venv
- Cleanup scripts are created for both Windows (PowerShell) and Linux/macOS (bash) to handle venv deletion after process exit
- Improved error handling and user feedback throughout the uninstall process
