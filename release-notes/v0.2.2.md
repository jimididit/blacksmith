# 🔧 Blacksmith v0.2.2 - Critical Package Fix

This is a **critical bug fix release** that resolves a packaging issue in v0.2.1.

## 🐛 Bug Fixes

### Package Installation Fix

**Issue**: The v0.2.1 package published to PyPI was missing critical subpackages (`blacksmith.config`, `blacksmith.export`, `blacksmith.package_managers`, `blacksmith.utils`), causing `ModuleNotFoundError` when running the `blacksmith` command after installation.

**Fix**: Updated `pyproject.toml` to explicitly include all subpackages in the package distribution:

- `blacksmith.config`
- `blacksmith.export`
- `blacksmith.package_managers`
- `blacksmith.sets`
- `blacksmith.utils`

**Impact**: Users who installed v0.2.1 will need to upgrade to v0.2.2. The package will now install correctly with all required modules.

## 📦 Installation

```bash
# Upgrade from v0.2.1
pip install --upgrade jdi-blacksmith

# Or fresh install
pip install jdi-blacksmith
```

## ✅ Verification

After installing v0.2.2, verify the installation works:

```bash
blacksmith --version
# Should output: Blacksmith, version 0.2.2

blacksmith --help
# Should display the help menu without errors
```

## 📝 Technical Details

The issue was caused by incomplete package configuration in `pyproject.toml`. The `[tool.setuptools]` section only listed `["blacksmith", "blacksmith.sets"]`, causing setuptools to exclude other subpackages from the wheel distribution.

This has been fixed by explicitly listing all subpackages, ensuring the complete package structure is included in the distribution.

## 🙏 Apologies

We apologize for the inconvenience caused by v0.2.1. If you encountered installation issues, please upgrade to v0.2.2, which resolves this problem completely.
